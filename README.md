# NMA_Project
Do working memory and emotion share cortical control networks? Contrast analysis of HCP 3T task-fMRI (Glasser 360 parcels) from my Neuromatch Academy project

This project, completed during Neuromatch Academy's Computational Neuroscience course, asks whether working memory and emotion processing recruit shared control networks (frontoparietal, salience, dorsal attention) or rely on domain-specific regions. Using the parcellated HCP 3T task-fMRI dataset (100 subjects, 360 Glasser parcels), we computed per-subject contrasts for working memory (2-back − 0-back) and emotion (fear − neutral), ran group-level one-sample t-tests with Benjamini–Hochberg FDR correction, and compared the resulting maps.

The whole-cortex t-maps were weakly negatively correlated (r = −0.213, Pearson and Spearman agree). Among regions significant in both tasks, 78 responded in opposite directions and 48 in the same direction. Frontoparietal regions were strongly opposed (12 opposite, 2 same), while the largest same-direction group was in Visual2.
